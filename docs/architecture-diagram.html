ARCHITECTURE

PrecisionClock 系统架构

跨平台 SwiftUI 高精度时钟应用 — 视图层 / 业务层 / 系统层

DATA FLOW

单向数据流

  • 系统时钟 → Date() → @Published
  • @Published → SwiftUI 自动刷新 View
  • View 仅读取，不修改数据源

CROSS-PLATFORM

跨平台策略

  • iOS: CADisplayLink 120fps
  • macOS: Timer 120Hz
  • 仅 PrecisionTimer 需要条件编译

NETWORK

NTP 通信

  • NWConnection UDP 端口 123
  • 10 个可选时钟源，多次测量取中位数
  • 标准 NTP v4 算法计算偏差
